Transcript

Tableau Public has no publishing API. And no official library can build workbooks from scratch. Tableau Public Authoring MCP builds and publishes them anyway.

Describe a workbook in JSON. A dry run checks every field against the data, so a typo fails with the right names.

The compiler writes the workbook, and turns each CSV into the Hyper extract Tableau Public requires.

Then it opens the file in the real Tableau Public app, and photographs it. Five of Tableau's load rules only showed up that way. Every screenshot here is a generated workbook, untouched in Tableau.

Publishing drives Tableau's own save flow, in your signed-in session. It never reads credentials, and won't replace a live workbook unless told to.
